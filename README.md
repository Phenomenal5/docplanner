# 🌍 Docplanner Landing Page Clone

This project is a front-end clone of the **Docplanner Group** landing page, built using **HTML** and **CSS**. It is a static web page developed as part of a learning exercise to practice layout design, CSS structuring, and responsive content.

---
## 💡 Features

- Clean and structured layout.
- Responsive navigation bar.
- Sections for patient and doctor services.
- Cards displaying global reach and countries served.
- Modern design mimicking Docplanner’s aesthetic.
---
## 🔧 Technologies Used
- HTML
- SCSS
---
## 🎓 Purpose
 This project was completed as part of a web development learning checkpoint to practice:
- Semantic HTML structure
- CSS styling and layout
- Building a multi-section landing page
- Responsiveness and visual hierarchy
